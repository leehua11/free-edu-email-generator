## ⚡ What is UES?
UES provides instant temporary `@ues.edu.pl` email inboxes to help self-taught developers, students, and engineers receive verification codes and test signup workflows.

- **Instant Inbox Generation**: Zero sign-up, passwords, or personal data collected.
- **Student Perks Ready**: Verified support for GitHub Student Developer Pack, JetBrains All Products, Amazon Prime Student, and Notion.
- **24-Hour Privacy Purge**: Inboxes and messages auto-delete after 24 hours.
