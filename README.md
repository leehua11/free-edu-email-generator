## ⚡ Features

- **Instant Inboxes**: Zero registration, CAPTCHA, or personal data required.
- **Student Verification Ready**: Optimized for receiving OTP codes and activation links for developer student packs.
- **Privacy-First (24h Auto-Purge)**: Inboxes and all incoming emails automatically expire after 24 hours.
- **Legitimate Educational TLD**: Uses valid `.edu.pl` domains recognized by major verification filters.

## 🚀 Quick Usage Guide

1. Visit the web app: [https://www.ues.edu.pl/](https://www.ues.edu.pl/).
2. Choose a username or click **Generate** to receive your address (e.g. `yourname@ues.edu.pl`).
3. Enter your address on the target verification page.
4. Keep the [ues.edu.pl](https://www.ues.edu.pl/) tab open to read incoming activation codes in real-time.
